## 4. Limitations

- The notices lane is memory: a notice posted while the app is closed is
  gone with it (the command is too: it ends with the app).
- `find_tools` matches words, not meaning; a query in another language
  than the server's descriptions finds nothing and says what the catalog
  holds.
- The stop poll during a deployed model call is one query every 3 s on the
  control plane; a setting (`TurnWatch.stop_poll_seconds`), not yet in
  `config.toml`.
- A grant's prefix is the command's first word; Codex's chosen-length
  prefix waits for an interface that lets the person choose it (34).
- The mini set never asked for two reads in one batch, so the parallel
  group ran only offline; a batch of one is the ordinary GLM shape.
