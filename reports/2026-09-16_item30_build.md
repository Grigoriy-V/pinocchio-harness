## 4. The live measurement (the human's word, 2026-09-16: the full mini set)

No local run on GLM under the old texts existed (a local `loop_live` run
keeps its telemetry in a temporary room), and the 2026-09-12 batch is
Gemma in the deployed profile, so both sides were run the same afternoon
on the same model, locally: the old texts from a worktree at `728f7a8`
with the root's `.env`, the new texts from `main`. Mini set A B C F W H E
M, GLM 5.3 Flash through OpenRouter, eleven turns a side. Everything is
kept: `reports/prompt_runs/2026-09-16_item30_before/` and `_after/`
(the `loop_live` log, the room's `telemetry.sqlite3`, the trajectories and
their export), the blind batch `reports/judge/2026-09-16_item30/` (22
transcripts shuffled, `key.json`, three Sonnet judges' `votes_*.json`).

**Blind judges, rubric as reworded in this step, three judges, 0–10 a
transcript:**

| side | mean total | transcripts under 10 |
|---|---|---|
| before (old texts) | 9.91 | M: `set_goal` before a two-file task (b=1, all three judges); |
| after (new texts) | 9.91 | F: the same click sent a third time before switching to `evaluate` (b=1, all three) |

Identical means; each side lost one point of b on one transcript, both

**`loop_live` checks (outcomes, as reworded):**

| side | failed checks | why |
|---|---|---|
| before | 3 | H: one `search_history` call with bad arguments, then a good one (the answer right); E: two checks pinned since 27 step 3 to a refusal that no longer happens, the model used `replace_all` and the edit succeeded |
| after | 2 (1 after the rerun) | B: the provider gave no token for 308 s, the turn ended with nothing said; B rerun alone: passed. F: one `browser.stale_ref` on a click, then the count was read with `evaluate`; the answer says 2 |

**Sizes per turn (mean, the room's telemetry):** before 24,795 input /
118 output tokens, 2.9 model calls; after 25,357 / 164, 3.2 calls. The
brief is shorter by ~200 words but the tool schemas dominate (~9,500
tokens a call), and the after run's F spent nine calls on the stale ref.
Spend: the provider's price per call is not stored yet (roadmap 33); by
the 27.3 smoke's rate the two runs together are under a dime.

**Seen on the way:**
- C passed every folder check on both sides, and the after side's brief
  carried no folder rule at all (the room has no `AGENTS.md`): the
  runner's `where` line ("make a virtual environment and run its python")
  and the task's wording were enough for this model.
- E's two checks in `loop_live` ("the failure reached the loop as
  fs.ambiguous_edit", "tool_failed carries code and message") pin a
  refusal that `replace_all` made optional; they fail on both sides and
  should test the outcome (the file's content) — noted for the next
  `loop_live` edit, not this step's.
- One provider stall of 308 s inside a 20 s scenario ceiling: the
  ceiling does not cut a model call that has not started answering; the
  client's own 600 s timeout is what ends it (roadmap 31, the timeout
  clamp, or 33, the model layer).

**Verdict:** the new texts did not change what the model did on the mini
set, up or down, at 20% fewer words in the brief; the step's acceptance
holds.

## 5. Limitations

- The environment line is built when a thread's graph is built and the
  date changes only when the graph is rebuilt (a new process, a new
  thread); a long-lived local process shows the day it started. Roadmap
  33 (the cache boundary) is where the volatile line gets its own place.
- The person's `AGENTS.md` is read from the workspace root, not from the
  conversation's working folder; a rule for one project is a rule for all
  of this person's conversations. As before this step.
