# Item 16, built: tool contracts, `use_page`, the brief and the prompt cut

Built 2026-09-07 from `reports/2026-09-07_item16_research.md`. Offline
suite: 1172 passed, 31 skipped (the real-browser tests run where Chrome or
Edge is installed). Not yet run on a model: the mini set on either side is
the human's gate (paid), and the deployed side needs a deploy.

## 1. What changed

**The contract.** `Tool` has two new fields, `returns` and `leaves`, and
`Tool.contract` renders the description the model reads as three parts in a
fixed order: what the tool does and takes, `Returns: …`, `Leaves: …`.
`tests/test_tool_contracts.py` refuses any wired tool (the registry's twelve,
memory, history, goal, todo) that leaves one empty, checks the schema
carries all three, and checks the Hermes rule: `read_file`, `write_file`,
`edit_file`, `list_files` each say which shell command they replace, and
`run_command` says the reverse. Every tool's description was rewritten to
the shape; the facts that used to be in the brief about a tool moved into
that tool.

**The page tool.** `inspect_page` is gone. `use_page(action, …)` on the same
`BrowserSession`: open (a workspace HTML file, or a public URL), snapshot,
click, type, press, select, evaluate, screenshot, console. Every action
returns the title, the console errors since the last call, the structure
with refs and the visible text, with the action's own line first ("clicked
e1"). The page lives in `Pages`, held by the `CapabilityRegistry` so a
turn's calls find the same page whichever toolbox they come through (a
toolbox is built per thread, more than once), and is closed by the next
open or after 120 s without an action. The capability is `browser.page`.
The description is the human's condition: "the same thing as Playwright or
Puppeteer, packed into one tool", open first, refs from the latest result,
a screenshot the person has not seen, and "one screenshot is not a run".
Not replay-safe: a click on a page that died with its worker may already
have counted.

**The brief and the prompt.** The brief keeps what is true of the whole
grant or differs per profile; the tools carry the rest:

| gone from the brief | now in |
|---|---|
| the `run_command` contract (exit code, traceback, "the shell does not know inspect_page") | `run_command` |
| the observation clauses per tool | one sentence; each tool's own description |
| the documents line | `read_document` |
| routing between search / fetch / view, "leaves this machine" | one line; the tools |
| the memory lines | `remember_fact`, `search_memory` |
| the goal line's text | `set_goal`; one sentence stays |
| the retry clause of the work sentence | dropped (a failure says whether to retry) |
| "Reading a picture file shows it to you as a picture" | `read_file` |

`DEFAULT_SYSTEM_PROMPT` lost the standing-instructions sentence (the
overlay's frame says it). `WORKING_METHOD` lost "You are an agent, not an
oracle" and "Take steps small enough to check" became "Change one thing,
then run it". The planning line and `todo_write`'s description state the
condition — three or more parts, or more than five tool calls — instead of
"when you can hold the whole of it in your head" (ISS-0016).

**Around it.** Preflight opens a page and takes a screenshot through
`use_page`; the Telegram activity label; scenario F now asks for two
presses and checks that the model opened, clicked twice and answered "2";
`tools/prompt_scenarios.py`, the maps, `PRODUCT.md`, the README.

## 2. The prefix, measured

Local profile, the registry's twelve tools, chars (tokens ≈ chars/4):

| layer | before | after | Δ |
|---|---:|---:|---:|
| core prompt | 1,508 | 1,297 | −211 |
| brief | 5,359 | 3,431 | −1,928 |
| tool schemas | 8,918 | 11,901 | +2,983 |
| **total** | **15,785** | **16,629** | **+844 (+5 %)** |

The schemas grew because `use_page` is 2,648 chars against `inspect_page`'s
643 (nine actions in one description) and `run_command` took the contract
from the brief (+621). The brief and the core together shed 2,139. Net: the
request is about 210 tokens longer than before, and every tool now states
what it returns and leaves. Option (b), six page tools, would have been
another ~3,600 chars on top.

## 3. What is not done, and how it is checked

- No model has run on this. The check is the mini set (`scripts/loop_live.py`,
  F extended with two clicks) locally and then deployed; and G of the wider
  set for the whole page loop. ISS-0008, ISS-0010 and ISS-0016 stay open
  until those runs say what changed.
- `view_web_page` still exists beside `use_page open url`. Deployed it runs
  in the separate renderer Function; `use_page` runs in the worker's own
  Chromium under the same public policy. Whether the two collapse into one is
  a later decision, after the set has been seen with both.
- A page's idle close is a timer, not a turn-end hook: the runtime does not
  tell tools when a turn ends. 120 s after the last action is the guess;
  the number is in `IDLE_SECONDS`.
